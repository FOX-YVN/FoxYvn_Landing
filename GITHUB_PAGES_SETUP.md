# 🚀 GitHub Pages — Пошаговая инструкция

## ⚠️ ВАЖНО: GitHub Pages должен быть включен

Проблема: GitHub Pages не активирован в настройках репозитория.

---

## 📋 Пошаговая инструкция

### Шаг 1: Откройте настройки GitHub Pages

**Прямая ссылка:**
```
https://github.com/E3FE3/Fox_Yvn_Landing/settings/pages
```

Или вручную:
1. Откройте https://github.com/E3FE3/Fox_Yvn_Landing
2. Нажмите **Settings** (вверху)
3. В левом меню найдите **Pages**

---

### Шаг 2: Настройте Source (КРИТИЧНО!)

На странице Pages найдите раздел **"Build and deployment"**:

**ВАЖНО:** Выберите **"GitHub Actions"** (НЕ "Deploy from a branch"!)

```
Build and deployment
┌─────────────────────────────────┐
│ Source:                         │
│ ○ Deploy from a branch          │ ← НЕ ЭТО!
│ ● GitHub Actions                │ ← ВЫБЕРИТЕ ЭТО!
└─────────────────────────────────┘
```

Если есть кнопка **Save** - нажмите её.

---

### Шаг 3: Запустите Workflow вручную

1. Откройте Actions:
   ```
   https://github.com/E3FE3/Fox_Yvn_Landing/actions
   ```

2. В левом меню найдите **"Deploy to GitHub Pages"**

3. Справа нажмите кнопку **"Run workflow"** (серая кнопка)

4. В выпадающем окне:
   - Branch: **main** (должно быть выбрано)
   - Нажмите зеленую кнопку **"Run workflow"**

---

### Шаг 4: Дождитесь завершения

- Workflow займет **2-3 минуты**
- Обновите страницу и следите за статусом
- Когда появится ✅ зеленая галочка - готово!

---

### Шаг 5: Откройте сайт

После успешного деплоя сайт будет доступен:

```
https://e3fe3.github.io/Fox_Yvn_Landing/
```

---

## 🔍 Проверка статуса

### Убедитесь что Pages активирован:

На странице https://github.com/E3FE3/Fox_Yvn_Landing/settings/pages должно быть написано:

```
✓ Your site is live at https://e3fe3.github.io/Fox_Yvn_Landing/
```

Если видите это ☝️ - значит всё работает!

---

## ❌ Если всё ещё 404

### Проверьте эти моменты:

1. **Source должен быть GitHub Actions**
   - Settings → Pages → Source = "GitHub Actions"

2. **Workflow должен быть успешным**
   - Actions → последний "Deploy to GitHub Pages" = ✅ зеленый
   - Если ❌ красный - откройте его, скопируйте ошибку и покажите мне

3. **Подождите 5 минут**
   - Иногда GitHub Pages обновляется с задержкой
   - Очистите кэш браузера (Ctrl+F5)

4. **Проверьте переменные окружения**
   - `VITE_SITE_URL` должен быть задан для корректных OG/Canonical мета‑тегов
   - `VITE_ANALYTICS_ENDPOINT` опционален (если используете Umami)

---

## 🐛 Если Workflow падает с ошибкой

1. Откройте https://github.com/E3FE3/Fox_Yvn_Landing/actions
2. Нажмите на последний failed workflow (❌ красный)
3. Откройте шаг где произошла ошибка
4. Скопируйте текст ошибки и покажите мне
